# D.LEAGUE CARD VAULT

公開URL: https://teotsukaip.github.io/DCard/

「カメラを起動」を押し、Dリーグ.jpegの画像全体をカメラに映してください。画像の特徴と配置が3回連続で一致すると、元のJPEG画像が獲得演出とともにコレクションに追加されます。同じ画像は重複登録しません。

- カメラ映像は送信せず、端末内で照合します。
- 初回は画像認識ライブラリ（約10MB）を読み込みます。
- 明るい場所で、反射を避けて画像全体を大きく映してください。
- 保存先はこのブラウザです。ブラウザデータを消去するとコレクションも消えます。
- 画像選択でも指定画像との一致を確認できます。
- デモカードは演出確認専用です。
- これは指定画像の照合です。人物の本人確認・カードの真贋判定は行いません。

index.htmlとassets/が必要です。OpenCV.js 4.10.0を使用しています。ライセンスはassets/内に収録しています。
